# سین‌بک (SinBack)

اپلیکیشن اندروید برای ثبت و بررسی بک‌تست استراتژی‌های معاملاتی (ترید) — کاملاً آفلاین، بدون نیاز به اینترنت یا سرور. تمام اطلاعات فقط روی گوشی خود کاربر ذخیره می‌شه.

## امکانات

- ثبت بک‌تست با جزئیات کامل (نماد، تایم‌فریم، Entry/SL/TP، روند، BOS، OB، FVG، RSI، واگرایی و...)
- محاسبه‌ی خودکار نسبت ریسک‌به‌ریوارد (R)
- آمار عملکرد: نرخ برد، میانگین و مجموع R، بهترین/بدترین معامله، استریک پیاپی
- فیلتر و جستجو بر اساس نماد، تایم‌فریم، جهت (Long/Short)، نتیجه و تاریخ
- افزودن اسکرین‌شات به هر معامله
- خروجی گزارش کامل بک‌تست‌ها به‌صورت PDF
- پشتیبان‌گیری کامل (شامل اسکرین‌شات‌ها) و بازیابی کامل اطلاعات، حتی بعد از نصب مجدد اپ
- ورود با نام کاربری و رمز عبور، مخصوص هر کاربر و جدا روی همون گوشی (بدون حساب آنلاین)

## دانلود

آخرین نسخه‌ی APK رو از بخش [Releases](../../releases) این ریپازیتوری دانلود کن.

> روی گوشی اندرویدت، اگه پیام "منابع ناشناس" اومد، اجازه‌ی نصب رو بده.

## ساختار پروژه

این پروژه با [Capacitor](https://capacitorjs.com) یک اپلیکیشن وب ساده (HTML/CSS/JS خالص، بدون فریم‌ورک) را به اپ اندروید تبدیل می‌کند.

</div>

```
sinback-app/
├── www/                      # کد اصلی اپ (HTML/CSS/JS)
│   └── index.html
├── capacitor.config.json     # تنظیمات Capacitor (appId, appName, webDir)
├── package.json              # وابستگی‌های npm
└── .github/workflows/        # بیلد خودکار APK با GitHub Actions
```

<div dir="rtl">

## ساخت (Build) از روی سورس

بیلد به‌صورت خودکار با GitHub Actions انجام می‌شه: با هر push به شاخه‌ی `main`، یک APK جدید ساخته و به‌عنوان Artifact در تب Actions قابل دانلوده.

برای بیلد دستی (لوکال):

</div>

```bash
npm install
npx cap add android
npx cap sync android
cd android && ./gradlew assembleDebug
```
